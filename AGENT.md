
# Development Rules

## Role
Act as a senior full-stack software engineer.

## Before Development
- Understand the complete project.
- Inspect existing files before modifying them.
- Create an implementation plan.
- Identify dependencies and possible risks.
- Ask for clarification when requirements are unclear.

## Coding Standards
- Use clean, maintainable TypeScript.
- Follow reusable component architecture.
- Avoid unnecessary dependencies.
- Maintain consistent naming conventions.
- Never duplicate existing functionality.
- Follow responsive design principles.

## Development Workflow
1. Analyze requirements.
2. Design architecture.
3. Implement features in small stages.
4. Run the application.
5. Test implemented features.
6. Fix errors before proceeding.
7. Review the final implementation.

## Git Rules
- Never overwrite existing working code without checking.
- Never delete important files without permission.
- Never commit secrets or environment variables.
- Explain significant changes.
- Commit completed milestones.

## Testing Rules
- Run the build after major changes.
- Check browser console errors.
- Test desktop and mobile layouts.
- Write automated tests for important functionality.
- Never claim a feature works without verifying it.

## Security
- Validate user input.
- Protect API keys and credentials.
- Implement proper authentication and authorization.
- Never expose private environment variables.
